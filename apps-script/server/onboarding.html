Welcome to CipherSheet
CipherSheet allows you to encrypt individual cells in your spreadsheet. Each user generates a personal keypair — only selected collaborators who have registered their key can decrypt.

To start, click Generate key in the sidebar. Save the unlock password shown, then optionally set up a passkey for easier access.
Protecting a Cell
Once your key is active, select any cell in your sheet. Type the secret text you want to securely store into the CipherSheet text box, choose which collaborators can read it, and click Protect.

The cell will be replaced with ciphertext — only selected recipients can decrypt it.
Reading and changing data
Open the sidebar or sync from an encrypted cell (using the cell locator ) — if your key is one of the recipients, the plaintext appears in the sidebar automatically and you can edit and update it.
Keep Your Key Safe
CipherSheet uses a zero-knowledge architecture, your private key never gets to the cloud or Google.
Your private key is encrypted with the unlock password. Make sure the password is stored securely! If you lose it, your encrypted data is unrecoverable.
